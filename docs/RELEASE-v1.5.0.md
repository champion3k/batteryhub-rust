# v1.5.0 — уведомления, история заряда, RU/EN

## Новое

- **Уведомления о заряде**: низкий заряд, начало зарядки, 100%. Один общий трей-баннер,
  чтобы несколько событий не перекрывали друг друга.
- Пункт **«Не беспокоить»** в меню — полностью отключает уведомления.
- **История заряда**: локальный TSV за 30 дней и HTML-график в браузере.
  - 24 часа / 7 дней / 30 дней.
  - Минимум, максимум, изменение, число точек.
  - Скорость разряда в %/час и примерное время до нуля.
- Проверка обновлений переключена на **champion3k/batteryhub-rust** — upstream больше не заменит
  кастомную сборку.
- Исправлен адрес GitHub в окне запроса поддержки.

## Драйверы

- AJAZZ AJ159 APEX / AJ-серия (`3151:5007`) — проверено.
- Dark Project HS5 V2 — заряд по Bluetooth.
- DualSense / DualShock 4 — USB / Bluetooth.
- AULA F75 / F87 Pro / F99 — 2.4 ГГц (не проверено на живом F75).
- Attack Shark — Xenta `1D57:FA60` и Rongyuan `3151:402D`.
