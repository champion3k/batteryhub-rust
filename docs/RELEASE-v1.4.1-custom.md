# v1.4.1 — AJAZZ / AULA / Attack Shark / RU-EN

Кастомная сборка BatteryHub для Windows 10/11.

## Что нового

- **AJAZZ AJ159 APEX** и AJ-серия на приёмнике SONiX `3151:5007` — заряд через `0xF7` + `0x05`.
- **AULA F75 / F87 Pro / F99** — 2.4 ГГц, отчёт `0x13`, команда `0x4A`.
- **Attack Shark** — мыши на Xenta `1D57:FA60` и Rongyuan `3151:402D` и других приёмниках.
- **Русский интерфейс** — переключение English / Русский в меню, сохранение выбора.
- Переведено окно **«Запрос поддержки устройства»**.
- **Dark Project HS5 V2** — заряд по Bluetooth; донгл 2.4 ГГц заряд не передаёт.
- **DualSense / DualShock 4** — USB и Bluetooth.
- Установщик, автозапуск и лёгкий трей-виджет.

## Установка

Скачайте `BatteryHub-Taskbar-Setup-v1.4.1.exe`, запустите, выберите **Install**.
Права администратора не нужны. Правый клик по процентам — меню и выбор языка.

## Примечания

- AULA и Rongyuan-мыши добавлены по протоколам сообщества, на живом железе в этой сборке не проверялись.
- HS5 V2: подключите по Bluetooth, чтобы видеть заряд; 2.4 ГГц можно оставить для звука.
